# Giải thích thuật ngữ API

## Prompt đã gửi cho AI

### Tôi là ai / Bối cảnh

Tôi là thành viên mới của CLB Lập trình PTIT và đang tham gia dự án SmartCampus, ứng dụng di động giúp sinh viên tra cứu lịch học, phòng học trống và thông báo của trường. Tôi chưa hiểu thuật ngữ API.

### Chủ đề / Nội dung cần xử lý

Hãy giải thích API (Application Programming Interface) theo cách dễ hiểu cho người mới học lập trình.

### Yêu cầu

- Nêu API là gì bằng ngôn ngữ đơn giản.
- Dùng một ví dụ gần với chức năng lấy dữ liệu lịch học của SmartCampus.
- Mô tả ngắn gọn cách ứng dụng và máy chủ trao đổi yêu cầu, phản hồi.
- Kết thúc bằng một câu tóm tắt dễ nhớ.

### Không cần

Không cần giải thích sâu về giao thức, bảo mật, mã nguồn hoặc các loại API nâng cao.

## Câu trả lời của AI

## API là gì?

**API** (Application Programming Interface, giao diện lập trình ứng dụng) là một cách quy định để các phần mềm yêu cầu và trao đổi dữ liệu với nhau. Có thể hình dung API như nhân viên nhận gọi món: ứng dụng gửi yêu cầu theo đúng cách, máy chủ xử lý rồi trả kết quả về.

## Ví dụ với SmartCampus

Khi sinh viên nhập mã sinh viên để xem lịch học, ứng dụng có thể gửi mã đó đến máy chủ qua API. Máy chủ tìm lịch tương ứng và gửi dữ liệu lịch học về; ứng dụng dùng dữ liệu nhận được để hiển thị các môn và thời gian học.

## Tóm tắt

API giúp các phần mềm giao tiếp theo một quy ước. Ứng dụng gửi yêu cầu, máy chủ xử lý và trả dữ liệu. Có thể nhớ API như một cầu nối giúp ứng dụng lấy thông tin từ hệ thống khác.

## Tóm tắt sau khi đọc theo 3 bước

API là quy ước giúp các phần mềm giao tiếp và trao đổi dữ liệu. Trong SmartCampus, ứng dụng gửi mã sinh viên đến máy chủ để yêu cầu lịch học rồi nhận dữ liệu về để hiển thị. Có thể hình dung API như một cầu nối giữa ứng dụng và máy chủ.

## Quy trình lưu tài liệu Markdown

1. Soạn prompt với bối cảnh, nội dung cần xử lý và yêu cầu cụ thể.
2. Gửi prompt cho AI và nhận câu trả lời.
3. Đọc câu trả lời theo thứ tự: quét tiêu đề, đọc phần chữ đậm, rồi xem danh sách gạch đầu dòng; viết tóm tắt bằng lời của mình.
4. Dán prompt, câu trả lời và phần tóm tắt vào StackEdit, sau đó lưu hoặc tải xuống dưới tên `api_giai_thich.md`.
