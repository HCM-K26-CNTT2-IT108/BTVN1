CLB Lập trình PTIT là cộng đồng dành cho sinh viên yêu thích công nghệ. **CLB nổi bật với hoạt động học tập, chia sẻ kiến thức và cùng xây dựng dự án thực tế.**

## Hướng dẫn gia nhập

1. Tạo tài khoản GitHub và cài Git trên máy.
2. Mở Terminal và sao chép kho tài liệu onboarding:

   ```bash
   git clone https://github.com/clb-lap-trinh-ptit/onboarding.git
   cd onboarding
   ```

3. Đọc hướng dẫn trong kho và hoàn thành checklist thành viên mới.
4. Trao đổi với Ban Kỹ thuật nếu cần hỗ trợ.

## Checklist thành viên mới

- [x] Đọc README và quy tắc sinh hoạt của CLB.
- [x] Tham gia kênh thông tin chung của CLB.
- [ ] Hoàn thiện hồ sơ thành viên.
- [ ] Cài Git và tạo tài khoản GitHub.
- [ ] Chọn một buổi sinh hoạt kỹ thuật để tham dự.

## Lưu ý quan trọng

> **Thời hạn:** Hoàn thành các bước onboarding trong tuần đầu tiên kể từ khi gia nhập CLB.  
> **Quy tắc ứng xử:** Tôn trọng mọi thành viên, trao đổi lịch sự, ghi nguồn khi sử dụng tài liệu của người khác và không chia sẻ thông tin nội bộ khi chưa được phép.
